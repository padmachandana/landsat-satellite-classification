Landsat Satellite Land-Cover Classification
1. Problem Statement
The objective of this project is to develop and evaluate multiple supervised Machine Learning classification models to classify land-cover types using multispectral satellite measurements.

The project implements five classification algorithms and compares their performance using six evaluation metrics. An interactive Streamlit application is also developed to allow users to upload a labelled test dataset, compare the trained models, select an individual model, and inspect its evaluation metrics, confusion matrix, and classification report.

The five classification algorithms implemented are:
1. Logistic Regression
2. Decision Tree Classifier
3. K-Nearest Neighbors (KNN)
4. Gaussian Naive Bayes
5. Support Vector Machine (SVM)
The models are evaluated using:
- Accuracy
- Area Under the ROC Curve (AUC)
- Precision
- Recall
- F1 Score
- Matthews Correlation Coefficient (MCC)
2. Dataset Description
Dataset Name: Statlog (Landsat Satellite)

Source: UCI Machine Learning Repository

Dataset Link: https://archive.ics.uci.edu/dataset/146/statlog+landsat+satellite

The dataset contains multispectral values for satellite image pixels. Each record represents a pixel described by 36 numerical attributes. The target variable identifies the land-cover class.
Dataset Details
Property	Description
Dataset Name	Statlog (Landsat Satellite)
Training Instances	4,435
Testing Instances	2,000
Total Instances	6,435
Input Features	36
Target Variable	Class
Observed Classes	1, 2, 3, 4, 5, 7
Problem Type	Multiclass Classification


The dataset files supplied by UCI are used with their original split:
- sat.trn: 4,435 training records
- sat.tst: 2,000 testing records
The original UCI training and testing files were kept separate. The test file was not combined with the training file or used to train the models.
Input Features
The dataset contains 36 numerical attributes, named Attribute1 through Attribute36.
Target Classes
The target variable is Class. The observed class labels in the supplied dataset are 1, 2, 3, 4, 5, and 7.
Data Preprocessing
The following preprocessing steps were performed:
1. Loaded the original UCI training and testing files.
2. Assigned column names to the 36 input attributes and target variable.
3. Inspected dataset dimensions, data types, missing values, duplicate records, and class distribution.
4. Separated the input features and target variable.
5. Preserved the official UCI training and testing split.
6. Applied StandardScaler within Scikit-learn Pipelines for Logistic Regression, KNN, and SVM.
7. Trained Decision Tree and Gaussian Naive Bayes without feature scaling.
Training and Testing Split:
- Training instances: 4,435
- Testing instances: 2,000
- Input features: 36

4. Models Used and Evaluation Metrics
All five classification models were trained using the original UCI training file and evaluated using the original UCI testing file.

The following evaluation metrics were calculated:
- Accuracy: Measures the proportion of correctly classified instances.
- AUC Score: Measures the ability of the model to distinguish between classes using a multiclass One-vs-Rest approach.
- Precision: Measures the correctness of positive predictions.
- Recall: Measures the proportion of actual instances correctly identified.
- F1 Score: Represents the harmonic mean of precision and recall.
- MCC: Measures the overall quality of classification predictions using all confusion matrix outcomes.
Macro averaging was used for AUC, Precision, Recall, and F1 Score.

Observations on Model Performance
ML Model Name	Observation About Model Performance
Logistic Regression	Achieved an accuracy of 83.95% and an AUC score of 0.9755. It demonstrated reasonable classification performance, although its accuracy and MCC were lower than those of KNN and Decision Tree.
Decision Tree	Achieved an accuracy of 84.90%. It performed better than Logistic Regression and Gaussian Naive Bayes in accuracy, precision, recall, F1 score, and MCC. Its AUC score was the lowest among the five models.

Overall Winner for the Dataset
K-Nearest Neighbors (KNN) was the best-performing model based on overall classification results for the selected Landsat Satellite test dataset.

It achieved the highest accuracy of 90.45%, precision of 0.8951, recall of 0.8886, F1 score of 0.8916, and MCC of 0.8827.

Support Vector Machine achieved the highest AUC score of 0.9850. Therefore, while SVM demonstrated the strongest AUC, KNN was selected as the overall winner based on its performance across the other five metrics.
5. Streamlit Web Application
An interactive web application was developed using Streamlit and is designed as a satellite land-cover classification dashboard.
Application Features
1. Dataset Upload: Allows users to upload a labelled test dataset in CSV format containing all 36 input features and the target column Class.
2. Model Comparison: Evaluates all five saved classification models on the uploaded test dataset and displays their results together.
3. Model Selection: Provides a dropdown to select an individual trained classification model.
4. Evaluation Metrics: Displays Accuracy, AUC, Precision, Recall, F1 Score, and MCC for the selected model.
5. Confusion Matrix: Displays a confusion matrix to visualize actual and predicted classifications.
6. Classification Report: Displays class-wise precision, recall, F1 score, and support.
7. Results Export: Allows users to download the model comparison results as a CSV file.
The application loads the previously trained models from saved .joblib files and evaluates the uploaded labelled test dataset without retraining the models.
